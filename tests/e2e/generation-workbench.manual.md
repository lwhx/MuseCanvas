# 生成工作台验收

## 环境与记录规则
- 只使用经授权的测试账户/环境；不读取或记录密码、Cookie、API key。
- 未经额外授权，不调用真实付费生成。任务响应可通过浏览器测试工具拦截，以 queued/running/retry_wait/succeeded/failed/canceled fixture 覆盖。
- 每一项记录实际结果、视口、主题、截图/日志路径；未执行项保持待验收，不据源码勾选。
